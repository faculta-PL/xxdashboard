# Nazix

Nazix est un espace de travail collaboratif : notes, idées, projets, fichiers, équipe et chat.

## Démarrage

```bash
npm i
npm run dev
```

L’app écoute sur [http://127.0.0.1:3847](http://127.0.0.1:3847).

Copiez `.env.example` vers `.env` si besoin. Ne commitez jamais `.env`.

Cahier des charges (optionnel) : [CAHIER.md](CAHIER.md).
